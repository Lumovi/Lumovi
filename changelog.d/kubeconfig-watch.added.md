- **Lumovi notices your kubeconfig changing.** A context your cloud’s command-line tool adds
  appears within a second, without Reload. **Add a folder…** reads every kubeconfig in a folder
  and keeps up as files come and go. A file caught half-written keeps the contexts it had until it
  reads again, and says so. Lumovi never writes to any of them. On a server, the fleet’s
  kubeconfig file is read again when it changes.
