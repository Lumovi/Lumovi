- **Argo CD's and CloudNativePG's plugins draw pages of their own**, from code that comes with
  Lumovi and runs in the same sealed box, reading only what each file says, as you. Argo CD: an
  overview of every Application by project, and a tab on an Application with its sync, health,
  resources and history; its **Sync…**, **Refresh…** and **Delete…** there are changes you confirm
  in Lumovi's own dialog, shown as the cluster would make them. CloudNativePG: an **Overview** of
  every PostgreSQL cluster with its instances, backups, schedules and poolers, and a **Backup
  health** page; its **Back up now…** is confirmed the same way. A resource's row opens Lumovi's
  own list at that object.
